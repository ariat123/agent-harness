Running it for a team

It's a plan. I haven't rolled it out across a team yet.

Each week, pull each person's usage from the team's AI tool exports and join it to what that team already calls shipped, like merged PRs or meetings booked. Each pattern starts a different conversation.

  • High spend, nothing shipped: sit with them on one stuck thread. It's usually a loop, a missing brief or the wrong model.
  • Steady output, little spend: find the task they still do by hand and build the first workflow with them.
  • Expensive model on routine work: change the default, not the person.
  • One thread running for weeks: start fresh each week from a handoff file.

The hook

A Claude Code SessionEnd hook adds a line per session to a local ledger with its tokens, cost and the outcome tag the person or agent writes before closing. It reads only the tag line, never the conversation. Untagged spend shows up as its own number.
